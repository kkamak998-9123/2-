# 실손의료보험(실비) 청구액 계산기 — SPEC 초안 (v0, 2026-08-12)

> 상태: **초안 — 함께 다듬는 중.** 특히 아래 "세대별 규칙 테이블"의 수치는
> 표준약관 기준 best-effort 값이며 `[확정 필요]` 표시된 값은 검토·수정 대상.

## 목적
사용자가 병원 영수증에 찍힌 금액(급여 본인부담·비급여 등)을 입력하면,
실손보험 **1~4세대 각각의 표준 규칙**을 적용해 **예상 수령(청구 가능)액을
세대별로 나란히 비교**해 보여준다. 보험사별 상품 차이는 다루지 않고,
"세대별 표준" 기준으로 간략 계산한다.

핵심 아이디어: 사용자가 본인 세대를 몰라도 "내가 몇 세대면 얼마 받는지"를
한눈에 비교. 낸 돈 전액이 아니라 **자기부담금·공제·한도를 뺀 금액**만 나옴을 보여줌.

## 범위
- **포함**: 입원 / 통원(외래) / 처방조제, 급여·비급여 구분, 중요 비급여 특약
  (도수·체외충격파·증식치료 / 비급여 주사 / 비급여 MRI).
- **세대**: 1세대(구실손) / 2세대(표준화) / 3세대(착한실손) / 4세대.
- **제외(비범위)**: 보험사·상품별 개별 약관 차이, 4세대 비급여 이용량 보험료 할증,
  연간 누적한도 정밀 추적, 중복·비례보상, 갱신/무사고 등. → v1은 "1회 영수증 기준
  세대별 추정".
- **다음 단계(v2)**: 영수증 사진 업로드 → Claude 비전으로 금액 자동추출(OCR).

## 입력 (영수증에서 수동 입력)
1. 진료 구분: **입원 / 통원(외래) / 처방조제**
2. 병원 종별(통원 공제 차등용): **의원 / 병원·종합병원 / 상급종합병원**
3. **급여 본인부담금** (영수증의 '급여 - 본인부담금' 합계)
4. **비급여 금액** (일반 비급여 합계)
5. **특약 대상 비급여**(있으면 별도): 도수치료 등 / 비급여주사 / 비급여MRI 각 금액
   - 특약 대상 금액은 위 4번(일반 비급여)에서 제외하고 여기에 따로 입력

> 실손 청구 대상 = 환자가 실제로 낸 **본인부담금**. 급여는 공단부담을 뺀
> '급여 본인부담', 비급여는 전액이 대상.

## 세대별 규칙 테이블 (표준약관 기준 · 2026-08 웹조사 반영)

> 출처: 금융위원회 보도자료·정책문답, 생·손보협회 상품공시, 뱅크샐러드/교보생명 정리.
> 보험사·상품별로 세부는 다를 수 있어 **표준(디폴트) 값**으로 사용하고, 화면에 근거를
> 함께 표기한다. 여전히 불확실한 항목만 `[검토]`로 표시.

### 세대 구분 (2세대는 2-1 / 2-2로 분리)
| 세대 | 판매 시기 | 특징 |
|---|---|---|
| **1세대** (구실손) | ~2009.9 | 표준화 이전. 자기부담 0%로 단순화(실제론 상품 편차 큼, 1세대는 소수). |
| **2-1세대** (표준화 초기) | 2009.10~2015.8 | 급여·비급여 자기부담 10%(표준형). |
| **2-2세대** (표준화 후기) | 2015.9~2017.3 | 비급여 자기부담 20%로 상향(선택형). |
| **3세대** (착한실손) | 2017.4~2021.6 | 급여10%/비급여20%, 3대 비급여 특약 분리(30%). |
| **4세대** | 2021.7~ | 급여20%/비급여30%, 비급여 이용량 보험료 할증. |

### 자기부담 / 공제
| 세대 | 급여 자기부담 | 비급여 자기부담 | 통원 정액공제(의원/병원/상급) | 처방 공제 |
|---|---|---|---|---|
| 1세대 | 0% | 0% | 5천원 | 없음 |
| 2-1세대 | 10% | 10% | 1만 / 1.5만 / 2만 | 8천원 |
| 2-2세대 | 10% | 20% | 1만 / 1.5만 / 2만 | 8천원 |
| 3세대 | 10% | 20% | 1만 / 1.5만 / 2만 | 8천원 |
| 4세대 | 20% | 30% | 급여 1만/1.5만/2만 · 비급여 3만 | 급여 8천원 |

- **통원 공제 로직**: 급여·비급여 각각 **max(자기부담율 적용액, 병원별 정액공제)** 를 공제 후 지급.
- **입원**: 정액공제 없이 자기부담율만 적용. (2·3세대 연간 자기부담 상한 200만원 존재 → v1은
  1회 기준이라 미적용, 참고 표시만.)
- 4세대 비급여 통원 공제 = **max(30%, 3만원)** 중 큰 값.

### 중요 특약 (3·4세대 · 기본형에서 분리 계산)
비급여 도수·체외충격파·증식치료 / 비급여 주사 / 비급여 MRI. **자기부담 = max(30%, 2만원)**.
| 특약 | 연 한도 | 연 횟수 |
|---|---|---|
| 도수·체외충격파·증식치료 | 350만원 | 50회 |
| 비급여 주사 | 250만원 | 50회 |
| 비급여 MRI/MRA | 300만원 | — |

- **1·2세대**: 3대 비급여 특약 개념 없음 → 특약 대상 금액도 일반 비급여 규칙으로 통합 계산.
- 3세대 특약 자기부담율은 30%, 4세대도 동일(30%). 4세대는 비급여로 통합되나 위 한도·횟수 유지.
- (참고) 2026.7 예정 규제로 도수치료 횟수 제한이 강화될 예정이나, v1은 현행 기준으로 계산.

### 보장 한도 (간략)
- **입원**: 세대별 연 5,000만원 수준(급여+비급여 합산).
- **통원(외래+처방)**: 회당 한도. 2·3세대 외래 회당 약 20~25만원(연 180회), 4세대는 외래+처방
  합산 **회당 20만원·연 100회**.
- v1은 **1회 영수증** 기준이라 연간 누적 한도는 참고 표시만 하고, **회당 한도(20만원)만** 캡으로 적용.

## 계산 로직 (세대별 공통 뼈대)
```
청구대상 = 급여본인부담 + 비급여 (+ 특약대상 비급여)
세대별:
  급여 지급 = max(0, 급여본인부담 - 급여자기부담) 
  비급여 지급 = max(0, 비급여 - 비급여자기부담)
  통원이면 공제 = max(자기부담액, 병원별 최소공제) 적용
  특약 지급 = 특약별 규칙(자기부담·한도·횟수) 적용
  회당 한도 캡 적용
예상 수령액 = 급여지급 + 비급여지급 + 특약지급
```

## 출력 (세대별 비교)
표 형태로 1~4세대 각각:
- 청구 대상액 / 자기부담·공제 합계 / **예상 수령액** / 적용 규칙 요약
- 가장 많이 받는 세대 하이라이트
- 면책 문구

## 기술 스택 / 구조 (복지앱 패턴 재사용)
- **웹앱**: FastAPI + 정적 프론트(폼·비교표). 복지혜택 매칭 웹앱과 동일 구조.
- **계산 엔진**: 순수 파이썬 모듈(`calc.py`) + 규칙 테이블(`rules.py`) — 테스트 용이.
- **엔드포인트**: `POST /api/calc` (입력 JSON → 세대별 결과).
- v2 OCR: `POST /api/ocr` (이미지 → Claude 비전 구조화 추출 → 위 계산으로 연결).
- 외부 API/DB 불필요(순수 계산). 배포는 복지앱처럼 Render 가능.

## 면책 / 주의
- 표준약관 기준 **추정치**이며, 실제 지급액은 가입 상품·특약·갱신·약관에 따라 다름.
- 정확한 금액은 본인 보험사/약관으로 확인 필요(면책 문구 상시 표시).
