# 네이버 블로그 콘텐츠 파이프라인 SPEC (초안)

## 1. 목표
네이버 블로그 1개, 카테고리 2개에 대해 **매일 자동으로 글 초안을 생성**한다.
네이버는 공식 발행 API가 없으므로 **자동 발행은 하지 않고, 발행 직전 상태의 완성된 초안 파일**을 만드는 것까지가 파이프라인의 범위다. 실제 등록은 사용자가 네이버 블로그 에디터에 직접 붙여넣는다.

## 2. 채널 구성 (블로그 1개, 카테고리 2개)

### 2-1. 프로젝트 소개 채널
- **목적**: 이 저장소(`C:\Users\willo\Desktop\코딩`)에서 만들고 있는 프로젝트들(조특법, 비상장주식 평가, 프로젝트6 등)을 소개
- **글감 소스**: 해당 일자의 git 커밋/코드 변경 이력 (`git log`, `git diff`)을 분석해 "무엇을, 왜 만들었는지"를 설명하는 글로 자동 요약
- **커밋이 없는 날**: 최근 N일(예: 7일) 내 변경 이력 중 아직 다루지 않은 내용을 사용. 그마저 없으면 해당 날짜는 초안을 건너뛰고 스킵 로그만 남김 (억지로 지어내지 않음)

### 2-2. 회계/세무 정보 채널
- **목적**: 회계·세무 관련 정보를 찾는 독자 대상 정보성 콘텐츠
- **글감 소스**: 혼합
  1. **최신 이슈형**: 웹 검색으로 그날그날의 세법 개정, 회계기준 변경 등 이슈를 찾아 요약 (사실관계 확인 필요 — 출처 링크 필수 명시)
  2. **개념/실무 팁형**: 조특법, 비상장주식 평가, 재무비율 분석 등 기존 프로젝트에서 다루는 도메인 지식을 기반으로 한 설명글 (웹 검색 최소화)
  - 매일 두 유형을 번갈아 사용 (예: 이슈형/개념형 교대, 또는 요일별 배정)

### 2-3. 일기장 채널
- **범위 제외**: 개인적인 내용이라 AI가 대신 쓸 수 없음. 이번 파이프라인에서는 다루지 않음 (추후 별도 논의)

## 3. 발행 주기
- 두 채널 모두 **매일 1편씩**, 총 하루 2개 초안 생성
- `/schedule`(cron)로 매일 정해진 시간에 자동 실행

## 4. 산출물 형식
- 네이버 자동 발행이 불가능하므로 **텍스트/마크다운 초안 파일**로 저장
- 파일에 포함할 것:
  - 제목 후보 2~3개
  - 본문 (네이버 블로그 톤: 문단 짧게, 소제목 활용)
  - **이미지/사진 추천 및 배치 가이드** (어떤 장면에 어떤 이미지를 어디에 넣을지 문단 사이에 `[이미지: ~~]` 형태로 표시)
  - 태그 후보
  - (회계/세무 이슈형 글의 경우) 참고 출처 링크

## 5. 저장 위치 / 네이밍

```
블로그 자동화 프로젝트/
  drafts/

  SPEC.md
```
