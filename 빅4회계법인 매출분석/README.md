# 빅4 회계법인 매출 분석 (삼일·삼정·안진·한영)

## 자료 출처
금융감독원 전자공시시스템(DART) OpenAPI를 통해 각 법인이 직접 제출한 **회계법인사업보고서** 원문에서 추출.
(외부감사법 제25조에 따른 법정 공시 — 매년 결산 후 제출)

| 법인 | 결산기준(당기) | DART 접수번호 | 원문 파일 |
|---|---|---|---|
| 삼일PwC | 제55기 (2024.07~2025.06) | 20250930000188 | dart_원문/삼일_*.xml |
| 삼정KPMG | 2025사업연도 (2025.04~2026.03) | 20260629000229 | dart_원문/삼정_*.xml |
| 딜로이트안진 | 2025사업연도 (~2025.05 결산) | 20250901000442 | dart_원문/안진_*.xml |
| EY한영 | 제45기 (2024.07~2025.06) | 20250930000076 | dart_원문/한영_*.xml |

※ 법인별 결산월이 달라 "당기" 기준 시점이 완전히 동일하지 않음 (삼정이 가장 최근).

## 파일 구성
- `빅4회계법인_매출분석.xlsx`
  - **요약** 시트: 4개 법인 총매출(3개년) 및 당기 감사/세무자문/경영자문 비중 비교
  - **삼일/삼정/안진/한영** 시트: 법인별 상세 매출 내역(법정감사·임의감사, 세무조정·회계기장·기타세무, 경영자문 등 세부 항목 × 3개년)
- `dart_원문/`: DART에서 내려받은 원본 XML 공시 파일 (검증·재확인용)
