# 비상장주식 평가 계산기 — 재무자료 CSV 업로드 기능 스펙

## 목적
순손익가치·순자산가치 계산에 필요한 입력값(3개년 당기순이익, 세무조정 항목,
자산·부채총액)을 수기 입력 대신 CSV 업로드로 자동 채운다. 기존 수동 항목
추가 + 드래그 분류(A/B/C 영역) 기능은 그대로 유지하며, 자동 불러오기 후에도
항목을 추가/삭제/재분류할 수 있다.

## 업로드 파일 3종 (고정 CSV 서식)

### 1. 재무상태표.csv
```
항목,금액
자산총계,5000000000
부채총계,3200000000
```
→ "자산총계"/"부채총계" 값을 순자산가치 입력창(자산총액/부채총액)에 자동 반영.

### 2. 손익계산서_3개년.csv (한 파일에 3개년)
```
연도,당기순이익
2025,350000000
2024,290000000
2023,410000000
```
→ 연도 내림차순 정렬 후 최신연도부터 1년전(가중치3)/2년전(가중치2)/3년전(가중치1)로
자동 매핑. 각 연도의 A영역(당기순손익)에 "당기순이익" 항목으로 자동 생성.

### 3. 소득금액조정합계표_3개년.csv (한 파일에 3개년, 가산/차감 구분 포함)
```
연도,구분,과목,금액
2025,가산,접대비한도초과,15000000
2025,차감,이월결손금,20000000
2024,가산,감가상각비한도초과,8000000
```
→ "가산"은 B영역(익금산입·손금불산입), "차감"은 C영역(손금산입·익금불산입)에
연도별로 자동 배치. 배치 후에도 화면에서 드래그로 재분류 가능.

## 처리 방식
- 백엔드에 `POST /api/parse-financials` 엔드포인트 추가
  - multipart/form-data로 3개 CSV 파일을 받음 (balance_sheet, income_statements, adjustments)
  - pandas로 파싱 → 구조화된 JSON 반환:
    `{ net_asset: {total_assets, total_liabilities}, years: [{year, net_income, additions[], subtractions[]}, ...] }`
  - 파일 형식/컬럼 오류 시 400 + 명확한 한글 에러 메시지
- 프론트엔드: "재무자료 불러오기" 섹션에서 3개 파일 선택 후 "불러오기" 버튼 클릭
  → 응답을 받아 기존 state(순자산가치 입력값, 연도별 A/B/C 항목)를 자동 채움
  → 이후 기존 수동 추가/드래그 UI 그대로 사용 가능

## 테스트
- 가상 회사의 3개 CSV 샘플 파일을 만들어 `sample_data/`에 저장
- 업로드 → 자동 분류 → 계산까지 전체 흐름을 실제로 실행해 검증

## 비범위
- 재무상태표/손익계산서 원본(PDF, 회계프로그램 자체 서식)의 자동 파싱은 이번 범위 밖.
  위 고정 CSV 서식으로 변환해서 업로드하는 것을 전제로 한다.
