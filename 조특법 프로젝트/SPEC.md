# 조세특례제한법 개인·법인 특례 매칭 CLI — 스펙

## 목적
사용자가 자신(개인) 또는 자신이 속한 법인의 속성을 입력하면, 조세특례제한법 상
적용 가능성이 있는 특례 조항(소득세 또는 법인세)을 찾아 안내한다.
어디까지나 "1차 스크리닝" 도구이며, 최종 적용 여부는 세무사 등
전문가 확인이 필요하다는 점을 결과에 항상 명시한다.

## 버전 이력
- v1 (2026-08-01): 개인(소득세) 특례 18개 조항, CLI
- v2 (2026-08-01): 법인 전용 특례(지방이전·특구입주·고용/투자세액공제 등) 추가,
  기존 CLI에 통합

## 데이터 소스
- 국가법령정보센터 Open API (open.law.go.kr)
  - 조세특례제한법 조문 목록 + 본문 조회
  - API 키(OC)는 `.env`의 `LAW_API_KEY`에 저장, 코드에 하드코딩 금지, git 추적 제외
- 가져온 조문은 로컬 sqlite(`data/law_cache.db`)에 캐싱, 수동 갱신 명령으로 최신화
- 조문 원문에서 "적용대상/요건/감면율/한도금액"을 1차적으로 구조화(요약)하되,
  결과 화면에 반드시 조번호를 표시해 원문 대조를 유도

## 적용 범위
- 개인(거주자) 대상 소득세 특례: 근로소득자용 + 개인사업자용 (v1, 18개 조항)
- **법인 대상 특례 (v2 추가)**:
  - 6조·7조·18조의3·29조의6 등 기존에 "소득세 또는 법인세"로 함께 규정된
    조항의 법인 버전
  - 법인 전용 특례: 공장/본사 지방(수도권 밖) 이전, 특구(연구개발특구·제주·
    기업도시·기회발전특구 등) 입주기업 감면, 고용증대·통합투자세액공제 등
  - 부가가치세·개별소비세 등은 이번 버전도 제외

## 입력 항목 (질문 흐름)
1. 소득 유형: 근로소득자 / 개인사업자 / 법인 / 복수 선택
2. (개인 선택 시) 나이
3. 소재 지역: 수도권과밀억제권역 / 수도권(기타) / 수도권 인구감소지역 / 수도권 외
   (개인·법인 공통 지역 구분 재사용)
4. (개인사업자·법인인 경우) 업종, 창업(설립)일자
5. (법인인 경우) 기업 규모(중소/중견/대기업, 사용자 직접 선택), 지방 이전 여부,
   특구·산업단지 입주 여부
6. (근로소득자인 경우) 입사일자, 이전 재직 여부(경력단절 등)
7. 특수 조건: 청년 여부, 장애인 여부, 60세 이상 여부, 경력단절여성 여부 등
   (필요 항목만 순차 질문)

## 매칭 로직
- 조문별 요건을 구조화된 데이터(JSON/DB)로 저장
  - 필드: 조번호, 제목, 대상, 요건리스트, 감면율, 한도금액, 적용기한
- 사용자 입력값과 요건을 비교해 "적용 가능 / 요건 일부 불충족 / 확인 필요"로 분류

## 출력
콘솔에 리스트로 출력, "적용 가능" 항목 상단 정렬. 각 항목에 다음을 표시:
- 조번호
- 특례명
- 감면내용 요약
- **감면율**
- **한도 금액**
- 적용기한
- 확인사항 (요건 중 불확실/미확인 부분)

## 비범위 / 주의사항
- 법적 효력 있는 세무 자문 아님 (면책 문구 항상 표시)
- 부가가치세·개별소비세 등 유통·소비세 특례는 이번 버전도 제외
- 조문 캐시는 수동 갱신 (자동 크론 없음)
- 법인 업종·투자금액·상시근로자 수 증감 등 정밀 요건은 "확인 필요"로 보수적으로 분류

## 기술 스택
- Python, CLI (input() 기반 순차 질문 흐름)
- sqlite3로 조문 캐시
- requests + python-dotenv로 law.go.kr API 호출
