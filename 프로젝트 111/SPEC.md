# SPEC: DART 재무제표 시각화 + 업종별 재무비율 분석 CLI

## 1. 목적
기존 `프로젝트2번 기본 완성본.py`(DART 재무제표 조회·그래프 CLI)를 개선한다.
회사를 검색하면 (1) 원본 재무제표 지표를 그래프로 보여주는 기존 기능은 유지하고,
(2) 새로 업종을 자동 판별해서 그 업종에서 중요하게 보는 "추천 재무비율"과 필요한
계정과목을 안내하고, 사용자가 재무제표에 표시된 계정 중 해당하는 것을 선택하면
연도별 비율을 자동 계산·시각화한다.

향후(이번 스코프 아님) 이 로직을 웹으로 옮겨 드래그앤드롭/마우스 클릭 UI로 전환할
예정이므로, 이번 CLI 구현에서도 "계정 매핑" 단계는 프론트/백엔드 분리를 염두에 두고
로직과 입출력을 함수 단위로 깔끔하게 분리해 둔다.

## 2. 데이터 소스
- DART Open API (`dart_fss`), 기존 API KEY 재사용
- 재무제표: `dart.fs.extract()` — is/cis(손익), bs(재무상태표), cf/ccf(현금흐름표), 5개년
- 업종 분류: `dart.get_corp_list()`의 기업별 `sector` 필드 → 통계청
  `2. 한국표준산업분류표(제11차).xlsx` 매핑표로 정규화
  (`산업분류추가.py`의 `엑셀기준_하이브리드_분류()` 로직 이식/재사용)
  - 제조업(대분류 C)은 중분류까지 세분화, 그 외는 대분류만 사용
  - **비율 추천표는 대분류 기준**으로만 운용 (중분류 세분화는 동종업계 비교용이며
    이번 비율 추천 매핑에는 과도하게 세분화하지 않음)

## 3. 기능 범위 (Scope)

1. 회사 검색 (기존 로직 유지)
2. 5개년 재무제표 추출 (기존 유지)
3. **[신규] 업종 판별**: 대분류명 산출 → 업종군 표시 (예: "제조업", "건설업",
   "도매 및 소매업", "정보통신업", "금융 및 보험업" 등)
4. **[신규] 업종별 추천 비율 안내**: 고정 매핑표(코드 내 하드코딩, 아래 4절)를 조회해
   해당 업종군의 추천 비율 목록과 각 비율에 필요한 분자/분모 계정과목명을 출력
5. **[신규] 계정 매핑**: 재무제표 항목을 번호 목록으로 보여주고, 사용자가 각 비율의
   분자/분모에 해당하는 항목 번호를 입력 (기존 지표 선택 UX 재사용)
   - 매핑 결과는 `{비율명: {"분자": 계정명/값, "분모": 계정명/값}}` 형태의 자료구조로
     저장 (추후 드래그앤드롭 웹 UI로 옮길 때 이 구조를 그대로 매핑 대상으로 사용)
6. **[신규] 비율 계산**: 연도별(최대 5개년) 비율 계산, 배수/% 단위 자동 처리
7. **[신규] 결과 출력**: 연도별 비율 표 + 추이 그래프
8. 기존 원본 지표 그래프 기능 유지 (손익/재무상태/현금흐름 지표 선택 후 그래프)
9. **[개선] UX**: 잘못된 번호 입력 시 재입력 유도, 회사 재검색/처음으로 돌아가기 옵션
10. **[개선] 그래프**: 그래프 PNG 저장 여부 선택 옵션 추가
11. **[개선] 코드 구조**: 전역변수 의존 최소화, DART API 호출 실패·계정 없음 등 예외 처리 강화

## 4. 업종군별 추천 재무비율 (초안 — 검토/수정 필요)

| 업종 대분류 | 추천 비율 | 계산식 | 필요 계정(BS/IS) |
|---|---|---|---|
| 제조업 | 부채비율 | 부채총계 / 자본총계 | BS: 부채총계, 자본총계 |
| | 유동비율 | 유동자산 / 유동부채 | BS: 유동자산, 유동부채 |
| | 재고자산회전율 | 매출액 / 재고자산 | IS: 매출액, BS: 재고자산 |
| | 영업이익률 | 영업이익 / 매출액 | IS: 영업이익, 매출액 |
| | ROE | 당기순이익 / 자본총계 | IS: 당기순이익, BS: 자본총계 |
| 건설업 | 부채비율 | 부채총계 / 자본총계 | BS |
| | 유동비율 | 유동자산 / 유동부채 | BS |
| | 매출총이익률 | 매출총이익 / 매출액 | IS |
| | 수주잔고회전율 | ⚠️ 계산 불가 — 재무제표 미기재 항목, **사업보고서(수주현황) 참조 필요** | — |
| 도매 및 소매업 | 매출채권회전율 | 매출액 / 매출채권 | IS/BS |
| | 재고자산회전율 | 매출액 / 재고자산 | IS/BS |
| | 영업이익률 | 영업이익 / 매출액 | IS |
| 정보통신업/서비스업 | 영업이익률 | 영업이익 / 매출액 | IS |
| | ROE | 당기순이익 / 자본총계 | IS/BS |
| | 총자산회전율 | 매출액 / 자산총계 | IS/BS |
| 금융 및 보험업 | 자기자본비율 | 자본총계 / 자산총계 | BS |
| | BIS비율 | ⚠️ 계산 불가 — 위험가중자산 등 감독규정상 별도 산출값, **사업보고서/공시자료 참조 필요** | — |
| | 예대율 | ⚠️ 계산 불가 — 계정 세부 분류 필요, **사업보고서 참조 필요** | — |
| 기타 업종(매핑 없음) | 범용 기본 세트: 부채비율, 유동비율, 영업이익률, ROE | | BS/IS |

프로그램 동작 규칙: 위 목록에서 "⚠️ 계산 불가" 표시된 비율은 계정 매핑 단계에서
건너뛰고, 안내 문구("OO비율은 재무제표만으로 계산할 수 없어 사업보고서 등 원문
공시자료 확인이 필요합니다")만 출력한다. 실제 계정 매핑·계산은 나머지 비율에 대해서만
진행한다.

## 5. 비범위 (Out of scope)
- 웹 전환 (드래그앤드롭 UI) — 다음 단계에서 별도 진행
- 금융업 특화 비율(BIS비율, 예대율 등) — 계정체계가 상이해 별도 스코프 필요
- 원본 문서(PDF) 파싱, 해외 회계기준(IFRS 외) 대응
- 동종업계 비교 기능 (이미 `산업분류추가.py`에 있음, 이번엔 통합 안 함)

## 6. 기술 스택
- Python, `dart_fss`, `pandas`, `matplotlib`, `numpy` (기존과 동일)
- 위치: `프로젝트 111/` 폴더 (기존 `프로젝트2` 파일은 수정하지 않음)

## 7. 확인 필요 사항
- 4절 비율표가 실무적으로 타당한지, 업종별로 더/덜 필요한 비율이 있는지 검토 필요
- 건설업 항목 중 "수주잔고" 등은 재무제표만으로 계산 불가하여 제외 처리함 — 괜찮은지 확인
- 금융업은 이번엔 자기자본비율만 제공하고 나머지는 비범위 처리 — 괜찮은지 확인
