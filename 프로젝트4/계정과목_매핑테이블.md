# 반도체 기업 재무분석을 위한 필수 계정과목 매핑

## 1. 영업현금흐름 & 자유현금흐름 분석

### 필요 계정과목
| 구분 | 계정과목명 | 출처 | 설명 |
|------|----------|------|------|
| **영업현금흐름** | 영업활동현금흐름 | CF | 본업에서 창출한 현금 |
| **투자현금흐름** | 투자활동현금흐름 | CF | 투자로 인한 현금 유출 |
| **Capex** | 유형자산취득(설비투자) | CF | 반도체 공장, 장비 투자 |
| **Capex(무형)** | 무형자산취득 | CF | 기술, 특허 등 R&D 투자 |
| **배당금** | 배당금지급 | CF | 주주 배당 현금 유출 |

### 계산식
```
자유현금흐름(FCF) = 영업현금흐름 - (유형자산취득 + 무형자산취득)
FCF 마진(%) = FCF / 매출액 × 100
```

## 2. 영업이익률 분석

### 필요 계정과목
| 구분 | 계정과목명 | 출처 | 설명 |
|------|----------|------|------|
| **매출액** | 매출액 | IS | 반도체 판매 수익 |
| **영업이익** | 영업이익 | IS | 순수 사업 이익 |

### 계산식
```
영업이익률(%) = 영업이익 / 매출액 × 100

추이: 경기 상승기(40~50%) → 경기 하강기(10~20%)
```

## 3. Capex/매출 분석

### 필요 계정과목
| 구분 | 계정과목명 | 출처 | 설명 |
|------|----------|------|------|
| **매출액** | 매출액 | IS | 분모 |
| **설비투자** | 유형자산취득 | CF | 반도체 Fab 투자 |
| **R&D투자** | 무형자산취득 | CF | 신기술 개발 투자 |

### 계산식
```
Capex/매출(%) = (유형자산취득 + 무형자산취득) / 매출액 × 100

반도체 정상: 20~40%
Capex↓ = 경기 악화 신호
Capex↑ = 신공정 투자 (미래 경쟁력)
```

## 4. 부채비율 분석

### 필요 계정과목
| 구분 | 계정과목명 | 출처 | 설명 |
|------|----------|------|------|
| **총부채** | 부채총계 | BS | 유동부채 + 비유동부채 |
| **자본금** | 자본총계 | BS | 지배기업의 소유주에게 귀속되는 자본 |
| **장기차입금** | 장기차입금 | BS | 설비투자 자금 |
| **단기차입금** | 단기차입금 | BS | 운영 자금 |
| **이자비용** | 금융비용 | IS | 이자 비용 |
| **영업이익** | 영업이익 | IS | 이자 상환 능력 판단 |

### 계산식
```
부채비율(%) = 부채총계 / 자본총계 × 100
  반도체 정상: 50~150%

이자보상배수(배) = 영업이익 / 금융비용
  안정적: 5배 이상
  위험: 3배 이하

자기자본비율(%) = 자본총계 / (부채총계 + 자본총계) × 100
  안정적: 30~50%
```

## 5. 매출원가율 분석

### 필요 계정과목
| 구분 | 계정과목명 | 출처 | 설명 |
|------|----------|------|------|
| **매출액** | 매출액 | IS | 분모 |
| **매출원가** | 매출원가 | IS | 생산 비용 |
| **판매비** | 판매비 | IS | 판매 비용 |
| **관리비** | 관리비 | IS | 관리 비용 |

### 계산식
```
매출원가율(%) = 매출원가 / 매출액 × 100
  생산 효율: 낮을수록 좋음
  반도체 정상: 35~60%

매출총이익률(%) = (매출액 - 매출원가) / 매출액 × 100
  = 100% - 매출원가율

영업이익률(%) = 영업이익 / 매출액 × 100

SGA율(%) = (판매비 + 관리비) / 매출액 × 100
  반도체 R&D 포함: 15~25%
```

## 6. 추가 분석 계정과목

### 자산 효율성
| 계정과목명 | 출처 | 용도 |
|----------|------|------|
| 총자산 | BS | 자산회전율 = 매출 / 총자산 |
| 유형자산 | BS | 설비 규모 = 유형자산 / 총자산 |
| 매출채권 | BS | 매출채권회전율 = 매출 / 매출채권 |
| 재고자산 | BS | 재고회전율 = 매출원가 / 재고자산 |

### 수익성
| 계정과목명 | 출처 | 용도 |
|----------|------|------|
| 순이익 | IS | ROE = 순이익 / 자본 |
| 자본총계 | BS | ROE 분모 |
| 총자산 | BS | ROA = 순이익 / 총자산 |

### 현금흐름 추가 항목
| 계정과목명 | 출처 | 용도 |
|----------|------|------|
| 운전자본변화 | CF | 경기 신호 (재고↑ = 수요약세) |
| 금융활동현금흐름 | CF | 차입/상환 추이 |
