# KODEX 반도체 ETF 35개 기업 - 재무분석 가이드

**프로젝트:** 반도체 기업 재무제표 분석  
**기간:** 2023~2025년  
**데이터:** 35개 기업의 3대 재무제표 (BS, IS, CF)

---

## 1. 재무상태표(Balance Sheet) - 핵심 항목

### 자산 측면

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **고정자산** | ★★★★★ | 반도체 설비 = 회사의 생산능력 |
| 유형자산 | ★★★★★ | 반도체 공장(Fab), 장비 규모 |
| 감가상각누계액 | ★★★★ | 설비의 경시 정도 파악 |
| 무형자산 | ★★★ | 기술, 특허 가치 (중요하지만 평가 어려움) |
| **유동자산** | ★★★★ | 단기 운영 자금 |
| 재고자산 | ★★★★ | 수요 변화 대응 능력 |
| 매출채권 | ★★★ | 고객 신용도, 매출 질 판단 |

### 부채 측면

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **차입금** | ★★★★★ | 대규모 설비투자 자금 조달 |
| 장기차입금 | ★★★★ | 설비 투자 자금 |
| 단기차입금 | ★★★ | 운영 자금 및 금리 부담 |
| **미지급금** | ★★★ | 공급사 신용 상태 |

### 자본 측면

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **자본금** | ★★ | 기본 정보 |
| 이익잉여금 | ★★★★ | 누적 수익성, 배당 여력 |
| 자본금/자산 비율 | ★★★★ | 재무 건전성 지표 |

## 2. 손익계산서(Income Statement) - 핵심 항목

| 항목 | 중요도 | 분석 포인트 |
|------|--------|-----------|
| **매출액** | ★★★★★ | 반도체 수요, 가격 추세 파악 |
| 매출 구성 | ★★★★ | 메모리(D램, NAND) vs 비메모리 비중 |
| **매출원가** | ★★★★★ | 생산 효율성, 가동률 반영 |
| 매출원가율 | ★★★★★ | 제조 경쟁력 (낮을수록 좋음) |
| **판매비+관리비** | ★★★★ | R&D 비용 포함 (기술 투자 강도) |
| R&D 비율 | ★★★★★ | 신기술 개발 여력 (15~25% 정상) |
| **영업이익** | ★★★★★ | 핵심 수익성 (순수 사업 이익) |
| 영업이익률 | ★★★★★ | 순환주기에 따라 크게 변동 |
| **금융비용** | ★★★★ | 높은 부채로 인한 이자 부담 |
| **당기순이익** | ★★★★ | 최종 수익성 (하지만 투자는 영업이익 중심) |

### 비율 분석
- 매출원가율 추이 → 효율성 개선/악화
- 영업이익률 추이 → 경기 순환성 파악
- R&D 비율 → 기술 경쟁력 유지

## 3. 현금흐름표(Cash Flow Statement) - 핵심 항목

### 영업현금흐름 (Operating Cash Flow)

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **영업현금흐름** | ★★★★★ | **가장 중요** - 실제 현금 창출 능력 |
| 순이익 조정액 | ★★★ | 현금화되지 않은 항목 |
| 운전자본 변화 | ★★★★ | 재고, 외상 변화 = 경기 신호 |

### 투자현금흐름 (Investment Cash Flow)

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **자본지출(Capex)** | ★★★★★ | 반도체는 매출의 20~40% 필요 |
| 설비투자 | ★★★★★ | 신공정(7nm, 5nm...) 개발 투자 |
| 연구개발 현금화 | ★★★ | 기술 고도화에 현금 투입 |
| **자유현금흐름(FCF)** | ★★★★★ | **가장 중요** = 영업현금흐름 - Capex |

### 재무현금흐름 (Financing Cash Flow)

| 항목 | 중요도 | 이유 |
|------|--------|------|
| **차입금 증감** | ★★★★ | 설비투자 자금 조달 방식 |
| **배당금 지급** | ★★★ | 주주 환원 여력 |

## 4. 주요 재무비율 (Financial Ratios)

### 수익성 지표

| 비율 | 계산식 | 반도체 적정치 | 의미 |
|------|--------|-----------|------|
| **ROE** | 순이익 / 자본 | 10~20% | 자본 효율성 |
| **ROA** | 순이익 / 자산 | 5~15% | 자산 효율성 |
| **영업이익률** | 영업이익 / 매출 | 15~30% | 순수 사업 수익성 |
| **매출총이익률** | (매출-원가) / 매출 | 35~55% | 생산 경쟁력 |

### 안정성 지표

| 비율 | 계산식 | 반도체 적정치 | 의미 |
|------|--------|-----------|------|
| **부채비율** | 총부채 / 자본 | 50~150% | 재무 레버리지 |
| **이자보상배수** | 영업이익 / 이자비용 | 5배 이상 | 이자 상환 능력 |
| **자기자본비율** | 자본 / 총자산 | 30~50% | 재무 안정성 |

### 유동성 지표

| 비율 | 계산식 | 반도체 적정치 | 의미 |
|------|--------|-----------|------|
| **유동비율** | 유동자산 / 유동부채 | 100~150% | 단기 상환 능력 |
| **당좌비율** | (유동자산-재고) / 유동부채 | 70~100% | 즉시 상환 능력 |

### 효율성 지표

| 비율 | 계산식 | 반도체 특성 | 의미 |
|------|--------|-----------|------|
| **자산회전율** | 매출 / 평균자산 | 0.3~0.6배 | 반도체는 낮음 (설비 많음) |
| **재고회전율** | COGS / 평균재고 | 4~8배 | 경기에 따라 변동 |
| **매출채권회전율** | 매출 / 매출채권 | 10~15배 | 대고객사 신용 조건 |

### 현금흐름 지표

| 비율 | 계산식 | 반도체 적정치 | 의미 |
|------|--------|-----------|------|
| **FCF** | 영업CF - Capex | 양수 유지 | 배당/부채상환 여력 |
| **FCF 마진** | FCF / 매출 | 5~15% | 실질 자유 현금 |
| **Capex/매출** | 설비투자 / 매출 | 20~40% | 투자 강도 |

## 5. 추이 분석 (Trend Analysis) - 3~5년 기준

### A. 경기순환 파악

```
매출액 추이 → 영업이익률 추이 → FCF 추이

경기 상승기: 매출 ↑, 이익률 ↑, FCF ↑
경기 하강기: 매출 ↓, 이익률 ↓, FCF ↓
```

### B. 경쟁력 변화

```
① 매출원가율 (낮아지면 경쟁력 ↑)
② R&D 비율 (기술투자 지속성)
③ 설비투자(Capex) 규모 (미래 경쟁력 대비)
```

### C. 재무건전성 변화

```
① 부채비율 추이 (상승 = 위험신호)
② 이자보상배수 (하락 = 위험신호)
③ 자기자본비율 (하락 = 재무 악화)
```

### D. 주요 신호

```
⚠️ 위험신호:
- 매출 감소 + 영업이익률 급락
- Capex 축소 (미래 경쟁력 감소)
- 부채 급증 + FCF 악화
- 재고 누적 (수요 약세)

✓ 긍정신호:
- 매출 성장 + 이익률 개선
- 높은 FCF + 배당 증가
- 신공정 투자(R&D ↑)
- 부채비율 개선
```

## 분석 우선순위 (중요도 순)

1. **영업현금흐름 & 자유현금흐름** → 실제 수익 창출 능력
2. **영업이익률** → 순환주기 위치 파악
3. **Capex/매출** → 미래 경쟁력 투자
4. **부채비율** → 재무 안정성
5. **매출원가율** → 생산 효율성
6. **3~5년 추이** → 경기순환 위치 파악
