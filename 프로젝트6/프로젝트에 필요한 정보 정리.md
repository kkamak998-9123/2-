## **PART II. 분석**

### **📊 분석 1 — 현금흐름 및 설비투자(Capex) 사이클 분석**

**목표:** 이익이 실제 현금흐름으로 전환되는지, 대규모 설비투자 부담이 재무구조를 압박하는지 확인

**1.1 필요 데이터**

* 매출액 (IS)  
* 영업이익 (IS)  
* 영업활동현금흐름 (CF)  
* 투자활동현금흐름 (CF)  
* 재무활동현금흐름 (CF)  
* 유형자산의 취득 (CF)  
* 무형자산의 취득 (CF)  
* **EBITDA** (=영업이익+감가상각비, 외부 데이터 소스 필요 — 25년 자료로 입력완료.  
* 

**1.2 계산 지표**

| 지표 | 산식 | 의미 |
| ----- | ----- | ----- |
| 매출액증가율 | (당기매출액 / 전기매출액) \- 1 | 외형 성장, 업황 방향성 |
| 영업이익률 | 영업이익 / 매출액 | 본업 수익성 |
| 영업활동현금흐름 전환율 | 영업활동현금흐름 / 영업이익 | 이익의 현금화 수준 |
| Capex집중도 | (유형자산의 취득 \+ 무형자산의 취득) / 매출액 | 설비투자 부담 수준 |
| 잉여현금흐름(FCF) | 영업활동현금흐름 \- (유형자산의 취득 \+ 무형자산의 취득) | 투자 이후 실제 남는 현금 |
| FCF마진 | FCF / 매출액 | 투자 부담을 감안한 현금창출력 |
| **EBITDA마진율** | **EBITDA / 매출액** | **감가상각 부담을 제외한 실질 영업 수익성** |
| **Capex/EBITDA** | **(유형자산의 취득+무형자산의 취득) / EBITDA** | **현금창출력 대비 투자 강도 — 1 초과 시 EBITDA로 투자를 못 메우는 구간** |

**1.3 이상징후 예시**

* **영업이익 증가 \+ 영업활동현금흐름 감소** → 이익의 질 저하 가능성  
* **영업활동현금흐름 전환율 \< 0** → 회계상 이익과 현금흐름 괴리  
* **Capex집중도 3년 연속 상승 \+ FCF 마이너스 지속** → 투자부담 심화, 자체 현금창출로 투자 충당 불가 가능성  
* **투자활동현금흐름 유출 확대 \+ 재무활동현금흐름 유입 확대** → 외부 차입·자본조달로 설비투자를 충당하는 구조 가능성  
* **영업이익률은 낮은데 EBITDA마진율이 크게 높음** → 감가상각비 비중이 매우 큰 자본집약 구조(설비 노후화·재투자 부담 상존)  
* **Capex/EBITDA \> 1 지속** → 벌어들이는 현금창출력만으로 설비투자를 감당 못하는 상태, 외부조달 의존 심화 신호

### **📊 분석 2 — 재고자산·매출채권 기반 업황 사이클 리스크 분석**

**목표:** 반도체 업황(다운사이클·업사이클)에 따른 재고 누적과 매출채권 회수 리스크 확인

**2.1 필요 데이터**

* 매출액 (IS)  
* 매출원가 (IS)  
* 재고자산 (BS)  
* 매출채권 (BS)

**2.2 계산 지표**

| 지표 | 산식 | 의미 |
| ----- | ----- | ----- |
| 매출총이익률 | (매출액 \- 매출원가) / 매출액 | 판가·가동률 수준 |
| 재고자산비율 | 재고자산 / 매출액 | 재고 누적 부담 |
| 재고자산증가율 | (당기재고자산 / 전기재고자산) \- 1 | 재고 축적 추세 |
| 재고자산회전일수 | (평균재고자산 / 매출원가) × 365 | 재고 소진 속도 |
| 매출채권회전일수 | (평균매출채권 / 매출액) × 365 | 채권 회수 속도 |

**2.3 이상징후 예시**

* **매출 감소 \+ 재고자산 증가** → 업황 둔화, 다운사이클 진입 신호 가능성  
* **매출총이익률 급락** → 판가 하락 또는 가동률 저하 가능성  
* **재고자산증가율 \> 매출증가율** → 재고 부담 가속, 재고자산 손상 위험 상승 가능성  
* **매출채권회전일수 급증** → 채권 회수 지연, 고객사(공급망) 재무상태 악화 가능성

### **📊 분석 3 — 재무건전성 및 이익배분 분석**

**목표:** 대규모 투자를 지속하는 가운데 재무구조 안정성이 유지되는지, 이익이 어떻게 배분되는지 확인

**3.1 필요 데이터**

* 총자산 (BS)  
* 부채총계 (BS)  
* 자본총계 (BS)  
* 비유동부채 (BS)  
* 금융비용 (IS)  
* 당기순이익 (IS)  
* 배당금지급 (CF)  
* 재무활동현금흐름 (CF)

**3.2 계산 지표**

| 지표 | 산식 | 의미 |
| ----- | ----- | ----- |
| 부채비율 | 부채총계 / 자본총계 | 레버리지 수준 |
| 비유동부채비율 | 비유동부채 / 부채총계 | 장기성 차입 비중(설비투자 재원 성격) |
| 순이익률 | 당기순이익 / 매출액 | 최종 수익성 |
| 이자보상배율 | 영업이익 / 금융비용 | 이자지급 여력 |
| 배당성향 | 배당금지급 / 당기순이익 | 이익 대비 주주환원 부담 |
|  |  |  |

**3.3 이상징후 예시**

* **부채비율 3년 연속 상승 \+ 영업이익 정체** → 레버리지 확대에 따른 재무 리스크 상승 가능성  
* **이자보상배율 하락 추세** → 금융비용 부담 증가, 이자지급 여력 저하 가능성  
* **당기순이익 감소 \+ 배당금지급 유지 또는 증가** → 배당 재원 부담, 향후 배당 지속가능성 우려  
* **재무활동현금흐름 유입 지속 확대** → 외부자금 조달 의존도 증가 가능성  
* **순차입금/EBITDA 급등** → 현금창출력 대비 순부채 부담 확대, 신용등급 하락 압력 가능성

## **PART II: 분석**

### **\[분석 1\] 수정 M-Score — 이익조정 가능성**

#### **1.1 모형**

Beneish(1999) 8변수 모형에서 **DEPI를 중립값 1.0으로 고정**한 7변수 모형.

M \= \-4.725  
    \+ 0.920·DSRI \+ 0.528·GMI \+ 0.404·AQI \+ 0.892·SGI  
    \- 0.172·SGAI \+ 4.679·TATA \- 0.327·LVGI

**절편 \= \-4.840 \+ 0.115 × 1.0 \= \-4.725**

#### **DEPI 제외 근거 (데이터로 확인됨)**

* 건설사는 중장비를 리스·임차 조달 → 유형자산 대비 감가상각비 비중이 작고 변동성 큼  
* 실제 수집 데이터에서 **감가상각비 커버리지 40/195 (20.5%)** → 애초에 계산 불가  
* 항을 삭제하지 않고 1.0으로 고정하는 이유: 절편과 판정 기준선(-1.78)의 캘리브레이션 유지

#### **1.2 변수 정의**

| 변수 | 산식 | 건설업 조정 |
| :---- | :---- | :---- |
| DSRI | (채권ₜ/매출ₜ) ÷ (채권ₜ₋₁/매출ₜ₋₁) | **채권 정의 2가지 (아래 참조)** |
| GMI | 매출총이익률ₜ₋₁ ÷ 매출총이익률ₜ | 당기 마진 ≤ 0이면 산출불가 처리 |
| AQI | (1−(유동자산+유형자산)/총자산)ₜ ÷ 동 ₜ₋₁ | 분모 0이면 1.0 |
| SGI | 매출ₜ ÷ 매출ₜ₋₁ | — |
| SGAI | (판관비/매출)ₜ ÷ (판관비/매출)ₜ₋₁ | — |
| TATA | (당기순이익 − 영업활동현금흐름) ÷ 총자산 | 건설업 판별력 최상위 |
| LVGI | (부채총계/총자산)ₜ ÷ 동 ₜ₋₁ | — |
| ~~DEPI~~ | **1.0 고정** | 적용 제외 |

#### **1.3 M\_std vs M\_adj (핵심 설계)**

| 버전 | DSRI 채권 정의 | 산출 | 용도 |
| :---- | :---- | :---- | :---- |
| **M\_std** | 매출채권 | 110 / 122 | 원 모형과 동일. 타 산업 비교 가능 |
| **M\_adj** | 매출채권 \+ **계약자산(미청구공사)** | 88 / 122 | 건설업 실질 반영 |
| **M\_gap** | M\_adj − M\_std | 88 | **\> 0.5면 미청구공사發 신호** |

**왜 계약자산을 채권에 더하는가**: 진행률을 조작하면(총예정원가 과소추정 → 진행률 과대) 매출·이익은 먼저 잡히지만 발주처에 청구할 근거가 없어 **미청구공사에만 쌓입니다.** 매출채권만 보는 표준 DSRI는 이 경로를 통째로 놓칩니다.

#### **1.4 판정 기준**

| M\_adj | 판정 | 실제 건수 |
| :---- | :---- | :---- |
| \> \-1.78 | 조작 가능성 (원 논문 기준) | **14건** |
| \-2.22 \~ \-1.78 | 보수적 경보선 | **13건** |
| ≤ \-2.22 | 특이신호 없음 | 61건 |

### **\[분석 2\] 미청구공사 기반 수익인식 리스크**

| 지표 | 산식 | 의미 |
| :---- | :---- | :---- |
| 미청구공사비율 | 계약자산 / 매출액 | 청구 못 한 수익 인식분의 부담 |
| **미청구\_매출\_갭** | 계약자산 증가율 − 매출 증가율 | **수익 인식 대비 청구 지연 (핵심)** |
| 순계약자산비율 | (계약자산 − 계약부채) / 매출액 | 수익인식-청구 순 괴리 |
| 미청구공사\_채권비중 | 계약자산 / (매출채권 \+ 계약자산) | 채권의 질 |
| 매출채권회전일수 | 평균매출채권 / 매출액 × 365 | 회수 속도 |

**⚠️ 증가율 폭발 방지 가드**: 전기 계약자산이 **전기 매출의 1% 미만**이면 증가율을 산출하지 않습니다(NaN). 이 가드가 없으면 잔액이 거의 0에서 증가할 때 증가율이 \+10,000% 같은 값이 나와 무의미한 경보가 발생합니다. (실제로 베노티앤알 2024에서 발생 → 수정)

### **\[분석 3\] 원가율 기반 진행률 조작 탐지**

| 지표 | 산식 |
| :---- | :---- |
| 원가율 | 매출원가 / 매출액 |
| **원가율변동** | 당기 원가율 − 전기 원가율 |
| 재고자산증가율 | 당기 재고 / 전기 재고 − 1 |
| 재고자산회전일수 | 평균재고 / 매출원가 × 365 |

**🎯 R3-2가 이 분석의 핵심입니다**: **원가율 3%p 이상 하락 \+ 미청구공사 증가**가 동시에 나타나면 진행률 조작의 전형적 패턴입니다. "덜 쓰고 더 벌었다고 주장하는데 정작 돈은 못 받고 있다"는 뜻이기 때문입니다. 총예정원가를 과소 추정하면 진행률이 부풀려지고, 매출·이익은 인식되지만 청구 근거가 없어 미청구공사에만 쌓입니다.

**실제 탐지 10건.** 이화공영 2025(원가율 −16.1%p, 미청구공사 \+140%), KCC건설 2024(원가율 −6.4%p, 미청구공사 \+71%)

### **\[분석 5\] 리스크 스코어링 — 두 축 분리**

#### **5.1 왜 단일 점수를 쓰지 않는가**

초기 설계는 단일 점수였으나, 검증 결과 **태영건설(부채비율 720%, 워크아웃 기업)이 "낮음"**으로 나왔습니다.

원인: 태영건설은 **분식이 아니라 유동성 위기**였습니다. M-Score 관련 규칙이 하나도 발동하지 않아 평균이 희석된 것입니다. 두 위험은 **성질이 다르므로 합산하면 안 됩니다.**

### **공사손실충당부채: 0이 아니라 "미공시"**

175개 조합에 **금액 0을 넣지 않았습니다.** loss\_provision\_status 컬럼으로 별도 관리합니다.

* RECOGNIZED (20건): 계정 존재  
* NOT\_DISCLOSED (175건): 계정 자체가 없음

**0으로 채우면 "손실충당부채 0 \= 건전"으로 오해됩니다.** 실제로는 인식 회피일 수도 있습니다.

## **PART V: ⚠️ 한계 (웹사이트에 반드시 명시)**

### **5.1 PF 우발채무를 볼 수 없음**

**태영건설의 실제 부도 원인은 부동산 PF 지급보증(우발채무)이었습니다.** 이건 재무상태표 본문이 아니라 **주석**에만 있어서 현재 데이터에 없습니다.

지금은 부채비율·이자보상배율로 **간접 포착**하고 있을 뿐입니다. 직접 보려면 사업보고서 주석 파싱이 필요합니다. → **확장 과제**

### **5.2 미성공사·하자보수충당부채 없음**

동일하게 주석 항목이라 미수집. 재고자산회전일수로 간접 대체.

### **5.3 M-Score 자체의 한계**

미국 **제조업** 표본(1982\~1992)으로 추정된 모형입니다. 한국 건설업에 그대로 적용하면 **위양성(false positive)이 상당히 발생**합니다. 단독 판정 근거로 쓰면 안 되고, 반드시 분석 2\~4의 건설업 고유 지표와 함께 해석해야 합니다.

### **5.4 이 서비스는 "분식 판정"이 아니라 "검토 후보 도출"**

**어떤 기업도 "분식했다"고 단정하지 않습니다.** 감사인이 추가 검토할 계정과 근거를 제시하는 것이 목적입니다. 화면 문구도 이 톤을 유지해야 합니다.

2. 

\# DART 기반 재무제표 이상징후 및 감사위험 탐지 서비스

\#\# PART I. 개요

이 프로젝트는 Open DART 공시 데이터를 기반으로 기업의 재무상태와 감사위험 신호를 탐지하기 위한 서비스입니다.

MVP 단계에서는 기업명 또는 기업번호를 입력하면 DART API를 통해 재무제표 데이터를 조회하고, 부채와 자본을 추출하여 부채비율을 계산합니다.

아키텍처는 다음과 같습니다.

\- \`frontend/\`: Cloudflare Pages에 배포할 Vite \+ React 프론트엔드  
\- \`backend/\`: FastAPI 기반 분석 API  
\- \`dart-fss\`: 백엔드에서만 실행되는 DART 조회 라이브러리

\#\# PART II. 데이터 출처

\- Open DART API  
\- \`dart-fss\`

주의사항:

\- DART API Key는 백엔드 환경변수로만 관리합니다.  
\- Cloudflare Pages 또는 기타 프론트엔드 환경에서는 \`dart-fss\`를 직접 실행하지 않습니다.

\#\# PART III. 인터페이스

사용자는 프론트엔드에서 기업명, 기업번호, 또는 \`corp\_code\`를 입력합니다.

프론트엔드는 다음을 수행합니다.

\- 입력값 검증  
\- 백엔드 API 호출  
\- 로딩 및 에러 표시  
\- 부채비율 결과 카드 렌더링

\#\# PART IV. 로직

MVP의 기본 흐름은 다음과 같습니다.

1\. 사용자가 기업명 또는 기업번호를 입력합니다.  
2\. FastAPI 백엔드가 해당 기업을 DART에서 검색합니다.  
3\. 최신 재무상태표에서 부채와 자본을 추출합니다.  
4\. 부채비율을 계산합니다.  
5\. 결과를 JSON으로 반환합니다.  
6\. 프론트엔드가 결과를 화면에 표시합니다.

부채비율 계산식:

\`부채비율 \= 부채 / 자본 × 100\`

출력 형식:

\- \`%\`  
\- 소수점 1자리까지 표시

\#\# PART V. 주요 기능

MVP 기능:

\- 기업명 또는 기업번호 입력  
\- DART 기반 기업 검색  
\- 최신 재무상태표 조회  
\- 부채/자본 추출  
\- 부채비율 계산  
\- 결과 카드 출력  
\- 기본 캐시 처리

향후 확장 예정:

\- 최근 5개년 재무제표 수집  
\- 계정 급변 탐지  
\- 순이익과 영업활동현금흐름 괴리 분석  
\- 감사위험 계정 추천  
\- 종합 리스크 점수화  
\- 리포트 생성

\#\# PART VI. 방법론

MVP에서는 완전한 표준화보다 주요 상장사의 재무상태표에서 안정적으로 \`부채총계\`와 \`자본총계\`를 찾는 것을 우선합니다.

적용 기준:

\- 연결재무제표 우선  
\- 없으면 별도재무제표 사용  
\- 한글/영문 계정명 후보군 기반 탐색  
\- 쉼표, 괄호 음수, 공백, \`-\` 값을 숫자로 정규화

UI는 재무/감사 분석 대시보드 톤으로 구성합니다.

\- 상단 브랜드 영역  
\- 검색 입력과 분석 버튼  
\- 핵심 지표 카드  
\- 부채비율 강조  
\- 결과 세부 카드  
\- 에러 및 warning 표시

상세 디자인 기준은 \[docs/design-guidelines.md\](/Users/da\_vid/Projects/risk\_analyzer/docs/design-guidelines.md)에 정리합니다.

\#\# PART VIII. 기타사항

\- 무료 배포 전제를 고려해 데이터베이스는 사용하지 않습니다.  
\- 기본 캐시는 서버 메모리 캐시를 사용합니다.  
\- 같은 기업 반복 조회 시 DART 호출을 줄이기 위해 TTL 캐시를 적용합니다.
